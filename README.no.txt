Styr Adax WiFi-ovnene dine direkte på hjemmenettet, uten Adax-skyen og uten internettforbindelse. Homey setter opp hver ovn over Bluetooth og snakker deretter med den lokalt, så endringer går raskt og virker selv om internett er nede. Du kan låse ovnen eller begrense hvor mye temperaturen kan endres med knappene på ovnen, og legge inn ovnens effekt slik at Homey Energi kan beregne forbruket.

Ovner som settes opp med denne appen fjernes fra Adax-appen og kan ikke lenger styres derfra. Støttet er Adax-ovner med WiFi- og Bluetooth-termostat (andre og tredje generasjon) på et 2,4 GHz WiFi-nett.
